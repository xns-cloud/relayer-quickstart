# Security Policy

## Reporting a vulnerability

Please report security issues privately — do **not** open a public issue.

Email **<support@xns.tech>** with `SECURITY` in the subject line. Include:

- what you found and where (file, endpoint, or port),
- the steps to reproduce it,
- what an unauthorized party could do with it,
- the version or image tag you tested.

You will get an acknowledgement within five business days. Please give us a
reasonable window to ship a fix before disclosing publicly.

## Scope

This repository contains a Docker Compose file and documentation only — no
application source code. Issues in the Relayer image itself
(`releases.scpri.me/xns-relayer`) are in scope for this contact address.

## Supported versions

The quickstart tracks the public **beta** channel. Fixes land on
`beta-latest`; there is no long-term-support branch during pre-release.
