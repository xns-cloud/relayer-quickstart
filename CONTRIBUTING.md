# Contributing to XNS Relayer Quickstart

Thank you for your interest in contributing!

## Development happens on GitLab

This GitHub repository is a **read-only mirror**. All development — issues,
merge requests, and code review — takes place on the canonical GitLab
repository:

> **<https://gitlab.com/scpcorp/relayer-quickstart>**

Pull requests opened on GitHub cannot be merged. Please open a merge request
on GitLab instead.

## How to contribute

1. Fork the project on [GitLab](https://gitlab.com/scpcorp/relayer-quickstart).
2. Create a feature branch from `main`.
3. Make your changes and commit.
4. Open a merge request against `main` on GitLab.

## Reporting issues

Please open an issue on the
[GitLab project](https://gitlab.com/scpcorp/relayer-quickstart/-/issues).
